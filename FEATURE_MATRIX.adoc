= AsciiDoc Feature Matrix
:toc: left
:toclevels: 2

This feature matrix maps the standardization, prototyping, testing, and implementation status of core AsciiDoc features. It serves as an authoritative guide for tracking spec conformance across the working group submodules and our own parser implementation.

== Status Legend

This matrix tracks the maturity and validation status of each language feature across the following categories:

Language Spec Status::
* *Standardized*: The feature is defined in an official, published module of the AsciiDoc Language Specification.
* *Outline*: The feature is currently defined in the AsciiDoc Language Specification Outline rather than a finalized module.

TCK Status::
* *TCK Covered*: Conformance tests have been accepted and merged into the official upstream `eclipse/asciidoc-tck` repository.
* *Proposed*: Conformance tests have been drafted and proposed as an active Merge Request on the upstream `eclipse/asciidoc-tck` repository.
* *Draft*: Conformance tests exist locally in our repository (`tests/tck_harness/`) but have not yet been proposed upstream.
