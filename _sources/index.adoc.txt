Welcome to the official documentation for **AsciiDoctrine**, a modern, specification-compliant AsciiDoc parser for Python.

AsciiDoctrine is designed from the ground up to provide a structured, type-safe representation of AsciiDoc documents, perfect for building renderers, static site generators, and custom documentation tools.

---

== Features

* **Lark-based Grammar**: Pure-Python parsing using standard EBNF syntax.
* **Semantic AST/ASG Convergence**: A type-safe representation aligned directly with the official Language ASG schema.
* **Two-Pass Resolution**: Centralized semantic resolution pass for attribute substitutions, include processing, and comment filtering.
* **Advanced Location Tracking**: Highly accurate, child-derived start and end line coordinates on block nodes.
* **Sphinx Integration**: Full extension support allowing you to author documentation in AsciiDoc and build it natively using Sphinx.
* **TCK Compliance**: Robust test suite matching the official AsciiDoc Technology Compatibility Kit.

== Quick Start

AsciiDoctrine implements a two-pass resolution pipeline. First, parse the raw source to a syntax-level AST. Then, resolve the AST to a semantic, queryable Abstract Semantic Graph (ASG):

[source,python]
----
from asciidoctrine import parse_to_ast
from asciidoctrine.resolver import ASGResolver

source = """
== Section Title
This is a *bold* word in a paragraph.
"""

# 1. Parse raw source to syntax-level AST
ast = parse_to_ast(source)

# 2. Resolve to semantic ASG (resolves attributes, includes, and filters comments)
resolver = ASGResolver(ast)
asg = resolver.resolve(ast)

# Iterate through sections in the ASG blocks list
for block in asg.get("blocks", []):
    if block.get("name") == "section":
        # The title is a list of inline nodes in the ASG schema
        title_nodes = block.get("title", [])
        title_text = "".join(node.get("value", "") for node in title_nodes if node.get("name") == "text")
        print(f"Found section: {title_text}")
----

== Sphinx Extension Integration

AsciiDoctrine comes with built-in Sphinx support, allowing you to author your documentation natively in AsciiDoc using the .adoc or .asciidoc extensions.

=== 1. Enable the Extension
Add `"asciidoctrine.sphinx_ext"` to the `extensions` list in your Sphinx `conf.py`:

[source,python]
----
# conf.py
extensions = [
    "asciidoctrine.sphinx_ext",
]
----

=== 2. Configure Document Suffixes
The extension automatically registers `.adoc` and `.asciidoc` source files. You can author your index or any sub-page in AsciiDoc and run standard Sphinx build commands:

[source,bash]
----
sphinx-build -b html docs/ docs/_build/html
----
