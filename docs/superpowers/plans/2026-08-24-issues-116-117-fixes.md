# Implementation Plan: Resolving GitHub Issues #116 and #117

This plan addresses and prioritizes the two open bug issues identified in the repository:
1. **[Issue #116](https://github.com/webmaven/asciidoctrine/issues/116) (Priority 1 - High)**: Table delimiter `|===` inside listing/literal blocks is parsed as a real table instead of literal text, and internal preprocessor markers leak into the AST and rendered output.
2. **[Issue #117](https://github.com/webmaven/asciidoctrine/issues/117) (Priority 2 - High)**: 4+ consecutive backtick inline code spans separated by commas wrap commas in `<code>` tags due to Earley parser ambiguity in unconstrained vs constrained monospace matching.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix verbatim block parsing when containing table delimiters, and fix inline monospace span parsing when multiple consecutive backtick spans appear on a line.

**Architecture:**
- For Issue #116: Ensure verbatim blocks (listing, literal, passthrough, comment) with outer markers protect internal characters from high-priority terminals (like `TABLE_CELL.20`), adjusting terminal priority ordering or verbatim token matching in `grammar.lark` / `preprocessor.py`.
- For Issue #117: Define constrained monospace inline parsing rules with proper non-whitespace / boundary semantics or adjust token priorities and base inline token definitions so that comma/space separators cannot be greedily matched across span boundaries.

**Tech Stack:** Python 3.10+, Lark Parser (Earley), Pytest, Docutils.

## Global Constraints
- Must maintain 100% pass rate across existing unit tests, doctests, and TCK test suite (`pytest -k "not functional"`).
- Strict adherence to the ASG schema format in `src/asciidoctrine/nodes.py`.
- Zero runtime regression in Lark parser performance or ambiguity warnings.

```python
def test_table_inside_listing_block_remains_literal():
    content = """[source,asciidoc]
----
[cols="1,2"]
|===
| A | B
| 1 | 2
|===
----"""

    assert len(doc.blocks) == 1
    assert isinstance(doc.blocks[0], Listing)
    assert "|===" in doc.blocks[0].content
    assert "ASCIIDOCTRINE_OUTER" not in doc.blocks[0].content
```

```python
def test_consecutive_comma_separated_backtick_spans():
    content = "hooks (`hook_0`, `hook_1`, `hook_2`, `hook_3`) end."
    doc = parse_to_ast(content)
    para = doc.blocks[0]
    # Check that inlines contain 4 separate code spans with comma/space separators
    code_spans = [
        span
        for span in para.inlines
        if isinstance(span, Span) and span.variant == "code"
    ]
    assert len(code_spans) == 4
    for i, span in enumerate(code_spans):
        assert span.inlines[0].value == f"hook_{i}"
```
