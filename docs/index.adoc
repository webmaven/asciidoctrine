Welcome to the official documentation for the **AsciiDoc Parser for Python**.

This documentation is self-hosted: it is rendered using Sphinx with our own `asciidoc_parser.sphinx_ext` plugin!

== Features

* **Lark-based Grammar**: High-performance parsing using the Earley and LALR algorithms.
* **Semantic AST**: A structured, type-safe representation of your document.
* **Sphinx Integration**: Author your documentation in AsciiDoc and render it with Sphinx.
* **TCK Compliance**: Developed against the official AsciiDoc Technology Compatibility Kit.

== Architecture

[NOTE]
====
This section is a summary of our architectural approach.
====

The parser operates in a multi-pass pipeline:

1. **Source Parsing**: Lark processes the source text into a CST.
2. **Transformation**: Our `AsciiDocTransformer` converts the CST into a structured AST.
3. **Semantic Resolution**: Attributes, includes, and links are resolved to produce the final ASG.
